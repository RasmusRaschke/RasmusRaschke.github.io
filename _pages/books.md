## A collection of books, primarily as reference for my projects and notes.

### Algebra
 - Sheldon Axler: [Linear Algebra Done Right](https://linear.axler.net/): I use this book as my main linear algebra reference. Fortunately, it is freely avaliable.
 - Paolo Aluffi: Algebra: Chapter 0: This is my main reference for abstract algebra and some cathegory theory.

### Analysis
 - Otto Forster: Analysis 1, 2, 3: These are my analysis reference books, covering real analysis in one and several variables, introductory ODEs and integration theory.
 - Walter Rudin: Principles of Mathematical Analysis: I worked with this book sometimes, especially to brush up on some topics in real analysis.
 - Klaus Jänich: Funktionentheorie: Similar to his book about topology, I really enjoyed this concise treatment of around one semester of introductory complex analysis.

### Differential Geometry
 - John M. Lee: Introduction to Smooth Manifolds: I read and used this book parallel to my first introduction to differential geometry and enjoyed it very much, like all books by this author. It also serves as my main reference.
 - John M. Lee: Riemannian Manifolds: The same can be said about this one.
 - John M. Lee: Introduction to Topological Manifolds: ...

### Topology
 - James Munkres: Topology: I used this book when I first learned about topology and found it quite useful.
 - Bodo von Querenburg: This German book is my main reference for point-set topology.
 - Allen Hatcher: [Algebraic Topology](https://pi.math.cornell.edu/~hatcher/AT/ATpage.html): I really enjoyed reading this book while I was introduced to the field of algebraic topology. It is feely available and my main reference for this field.
 - Klaus Jänich: Topologie: I read the German version of this book after I had already completed introductory point-set topology. The style of Prof. Jänich is really unique and a pleasure to read in my opinion.
